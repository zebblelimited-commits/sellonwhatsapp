Topship Open Server Docs
Description
Topship Open Server enables merchants and consumers have access to shipping endpoints, quotes endpoints, labels and waybills, payments and transactions, and so on.

Note

For your API keys, on both STAGING & PROD, please email the following to tech@topship.africa;
Full Name, Work Email Address, Company Phone Number, And Company Name.

This is an application solely built to manage merchant shipping inventory, history, and functions solely with topship. All endpoints have the below as base / parent url:

LIVE

https://api-topship.com/api

SANDBOX

Get Quotes And Prices
This resource returns prices, mode, currency, tier and so on. The duration key on the response object, specifies the approximate duration it will take for the shipment to arrive. While the pricing tier key, represents the category of shipping that the quote represents.

GET

/get-shipment-rate

Parameters

{
  "shipmentDetail": {
    "senderDetails": {
      "cityName": "string",
      "countryCode": "string"
    },
    "receiverDetails": {
      "cityName": "string",
      "countryCode": "string"
    },
    "totalWeight": "number"
  } 
}

Get Booked Shipments

This resource allows for consumers to cancel a non-attended shipment. Shipments with status of DRAFT or CONFIRMED, are eligible for cancellation. Note

Please note that shipments outside of DRAFT or CONFIRMED, cannot be cancelled by this resource.

POST

Book A Shipment As Draft
This resource gives the consumer the ability to book a shipment as draft. This means that the shipment will be saved on our database, but not yet paid for. The consumer can then make the payment using the /pay-from-wallet endpoint.

Note

Please note that the addressLine1, addressLine2 and addressLine3 fields have a maximum length of 45 characters.

Note

Please note that all charges are in KOBO and not Naira, so all values passed as charges should be multiplied by 100.

Note

Please note that the value passed to shipmentCharge is strictly gotten from getting quotes from /get-shipment-rate.

Note

Please note that the valueAddedTaxCharge (KOBO) is always 7.5% of the totalCharge. The value should always be ceiled (and not rounded up), to avoid decimals and loss of value.

/save-shipment
